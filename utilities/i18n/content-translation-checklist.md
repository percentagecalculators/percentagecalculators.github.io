# Content translation checklist (second pass: `content_html` + FAQ)

23 languages x 42 articles = 966 article items, plus 253 FAQ sets (127 Q&A per language) = 1,219 boxes. English source: `src/content/<slug>.json` (`content_html`, `faq`). About 67,183 words per language.

Infographics (`<figure>`/`<img>`, home page) are not imported: leave them out of the translated `content_html`.

**Read `content-translation-guide.md` first.** This is localisation against target-language search terms, grammar and usage, not a word-for-word translation.

Tick a box only when ALL are true: written in `src/content/i18n/<lang>/<slug>.json` (`content_html` / `faq` keys), `python3 utilities/i18n/validate.py <lang> <slug>` passes, numbers match English, terms match the language glossary, and the page was read by a second person.

## Before any language starts (once)

- [x] Heading ids: translated pages reuse the English heading ids (`english_heading_ids()` in `generate.py`)
- [x] Number check in `validate.py` (digits in article and FAQ identical to English); `add_content.py` merges an article/FAQ and validates
- [ ] Percent-sign spacing, digit style and currency policy confirmed per language (guide section 8)
- [ ] Reviewer assigned per language

## Per language, in this order

1. Glossary `src/content/i18n/<lang>/glossary.md` and LaTeX labels `latex_labels.tsv` written and reviewed
2. Pilots (home, one finance tool, one education tool) written and reviewed; comments folded into the glossary
3. Remaining articles, then FAQs
4. `generate.py` + silo rotation + `test_tools.js <lang>` + browser spot-check (3 pages), then commit
