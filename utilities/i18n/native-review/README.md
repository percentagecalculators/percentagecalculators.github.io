# Native review sheets

One sheet per language that has not yet had a native-speaker review: fa, pl, ro, tr, uk.
Each lists scope, the style decisions to confirm, every term the translators flagged, and a table of all 42 page names/titles/descriptions.
After a review, record the outcome at the bottom of the language's `glossary.md` and tick the reviewer box in `content-translation-checklist.md`.
