# Romanian (ro) glossary for tool pages, articles and FAQs

Decisions (made 2026-10-29):
- Variety: standard Romanian (Romania), with comma-below diacritics only: ș ț (never cedilla ş ţ), plus ă â î.
- Register: neutral instructional, impersonal where possible; otherwise informal-polite 2nd person singular ("tu": "Introdu", "Calculează", "tău"). No "dumneavoastră". Labels/buttons use the imperative ("Calculează", "Introdu valoarea"). Headings in sentence case; question headings end with `?`.
- Numbers, decimal point, thousands comma and `$` stay as in English (they match the calculator output and the validator): 12.5%, $1,250.00, never 12,5 or 1.250. `$` goes before the number.
- Percent: attached, `20%`. Prose: "procent" / "procente"; "la sută" only in spoken-style phrases.
- Quotation marks: „…” (low-high). Placeholder prefix "e.g. " -> "ex. ".
- Site name "Percentage Calculators" stays in English. Tool names follow search habit: "Calculator …" (calculator procente, calculator adaos comercial).
- Plurals: use the correct "de" rule with numerals of 20 or more ("20 de procente"); avoid in labels where possible.
